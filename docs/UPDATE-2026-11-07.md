## Add product images

1. Open **Admin → Products → New product** (or edit a product).
2. Under **Add an ImgBB image link**, paste either an ImgBB sharing link beginning `https://ibb.co/` or a direct image link beginning `https://i.ibb.co/`.
3. Select **Add image link** and check the preview.
4. Add more images if needed, reorder them with the arrows, then select **Save product**. The first image becomes the main product image. Up to ten images are supported.

No ImgBB API key is needed. Images must remain publicly accessible on ImgBB. Broken previews show an error and must be removed or replaced before saving.

**Why file uploads failed:** the configured bucket, `ucall-1.firebasestorage.app`, does not exist. ImgBB links work without this bucket. To enable direct file uploads later, create Storage in the Firebase console, check its billing requirements, set the exact bucket name in local/Vercel settings, then deploy `storage.rules`. No bucket or billing plan was created during this update.

## Order support and chat

Customers open **My orders → Get support** to choose:

- **Where is my order?** — current status and tracking guidance.
- **Faster delivery** — saves **Order prioritised** on an active order. It is a request to your team, not a guaranteed delivery date.
- **Delivery & address help** and **Cancellation, returns & refunds** — useful next steps.
- **Chat to agent** — starts a private conversation with your store.

In **Admin → Orders**, prioritised active orders appear first and can be filtered. In **Admin → Support chat**, select a customer, type under **Reply to customer**, and select **Send reply**. Replies update live. Unread indicators show new messages. Chats can be closed and reopened without losing their messages; each view shows the latest 100 messages.

Customers see a **New reply** badge on their order and can return to **Get support** later. Chat does not claim an agent is online or send email/push notifications.

## Run the checks

From PowerShell:

```powershell
Set-Location -LiteralPath 'C:\Users\Adeeba\OneDrive\Desktop\UCALL'
pnpm test
pnpm lint
pnpm build
pnpm test:emulators
pnpm test:authenticated
pnpm test:browser
```

Run emulator commands one at a time; they share local ports. Their data is isolated in `demo-ucall`. The authenticated browser suite disables payment/email providers and uses a separate local app on port 3001. The public browser suite can reuse the running app on port 3000.

For future Firestore rule updates, run `pnpm test:emulators` and then `pnpm rules:deploy`. The deployment script uses the configured service account, saves the previous rule release under ignored `.firebase/rule-backups`, and verifies the published release. Storage deployment needs an existing bucket and the appropriate permissions.

The source changes are in this local project. If your store is hosted on Vercel, redeploy this updated project there. See [verification results](VERIFICATION.md) for the final checked scope and service limitations.
