## Customer support

**Get support** now opens a dedicated `/orders/[id]/support` page on phones and computers. Quick-help options remain available, and Faster delivery marks the order prioritised in the admin order list. Conversations persist when the customer leaves and returns.

Customers and the owner can attach up to three photos to a message, including a photo without text. Phone images are resized before upload. Private images require the order owner's or sole admin's authenticated session; Firebase Storage is not required.

The support assistant uses **Groq**. Add your key to `GROQ_API_KEY` in the private `.env.local` file and the hosting environment, then restart/redeploy. The default `GROQ_SUPPORT_MODEL` is `llama-3.1-8b-instant`. Never prefix the key with `NEXT_PUBLIC_`. See [AI support setup](AI-SUPPORT.md).

Groq selects an approved support intent; all replies come from server-owned UCALL support templates. It cannot return general knowledge, programming answers, creative writing or arbitrary model text. Unrelated requests get a fixed refusal. Agent requests, unresolved issues, photos requiring review, provider failures and the attempt limit transfer the conversation with history to **Admin → Support chat → Needs an agent**. An admin reply takes over immediately. Without a configured key, customers are told that AI is unavailable and transferred to the team.

At the owner's request, new orders add **18% GST on top of merchandise prices**. Shipping is separate. Checkout, Razorpay amounts, order details, confirmation emails and the printed bill use the same saved tax and total. Amounts retain paise. Older orders retain their recorded charge and are not taxed again.

## Order status emails from Gmail

Order confirmations and status changes are queued for delivery from **ucallleather.india@gmail.com**. Customers receive confirmed, shipped, delivered and cancelled updates, with tracking when recorded, billing details and links to their order and support. Each event saves its own status and timestamp, so a delayed email does not claim to describe a newer stage. Repeating a status or editing tracking alone does not create a duplicate status notification.

Set `SMTP_USER=ucallleather.india@gmail.com` and add a Gmail App Password to the server-only `SMTP_PASS` setting. Google 2-Step Verification is required. `SMTP_PORT` defaults to `465`. See [Gmail email setup](GMAIL-EMAIL-SETUP.md). A normal Gmail password is not supported. Failed deliveries remain in the durable outbox for retry; the admin dashboard shows pending confirmations and status updates.
